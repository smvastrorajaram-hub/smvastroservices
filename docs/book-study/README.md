# பத்து நூல்களின் ஆய்வு மற்றும் பலன் விதிகள்

அளிக்கப்பட்ட பத்து PDF நூல்களிலும் மொத்தம் **3,889 பக்கங்கள்** உள்ளன. கிடைத்த எழுத்துப் பதிவுகள் பக்க வரிசையில் ஆய்வு செய்யப்பட்டன. கடைசித் தமிழ்ப் புத்தகத்தின் 213 பக்கங்களில் native text layer தமிழ் எழுத்துகளை விட்டுவிட்டதால், அதன் அனைத்து 437 பக்கப் படங்களுக்கும் OCR மீண்டும் செய்யப்பட்டது. OCR பக்கம் 5 வாசிக்க இயலாத பதிவு. படங்கள், அட்டவணை அமைப்பு, சூத்திரங்களின் எழுத்துக்கள், சேதமான மந்திரங்கள் முழுமையாகக் காட்சி முறையில் சரிபார்க்கப்படவில்லை. **எல்லா அசல் பக்கங்களும் முழுமையாகப் படிக்கப்பட்டதாக இப்பதிவு கூறவில்லை.**

[source-review.json](source-review.json) நூல் அடையாளங்கள், SHA-256, PDF பக்க எண்ணிக்கை, ஆய்வு வரம்பு மற்றும் மீதமுள்ள வரம்புகளைச் சேமிக்கிறது. நூல் கூறும் நிபந்தனையைச் சரிபார்ப்பது, பலன் நிகழும் அறிவியல் உறுதிப்பாடு அல்ல. BPHS II மொழிபெயர்ப்பாளர் பதிவை filename மூலம் நிர்ணயிக்கவில்லை; Remedies நூலின் PDF3 இரண்டாம் பதிப்பு 2010 என்கிறது.

## செயல்படும் மாற்றங்கள்

- புதிய கிரக–பாவ matcher உண்மையான D1 ஆட்சி, உச்சம், பாவ இருப்பு, பார்வை, இரு அதிபதி இடமாற்றம் மற்றும் கூட்டுச் சூழலைப் பொருத்துகிறது. ஆட்சி/உச்சம் மட்டுமே முழு Shadbala எனக் கருதப்படுவதில்லை.
- MD/AD நிபந்தனைகள் எல்லா சரிபார்த்த காலவரம்புகளிலும் முதலில் பொருத்தப்படுகின்றன. ஒரே கிரகம் MD/AD ஆக இருப்பது இரு தனித்த ஆதாரங்களாக எண்ணப்படுவதில்லை.
- கோச்சாரம் actual Swiss cache ராசியிலிருந்து பிறப்பு சந்திர ராசியை நோக்கிக் கணக்கிடப்படுகிறது. கணிக்கப்பட்ட தேதி forecast window மற்றும் active MD/AD இரண்டிலும் இருக்க வேண்டும். குரு 2/5/7/9/11, சனி 3/6/11 பட்டியலில் இல்லாத இடம் தானாகத் தீய பலன் ஆகாது.
- விருப்பப் பரிகாரம் உண்மையான பாவத் தொடர்பு அல்லது தரப்பட்ட MD/AD நிபந்தனை கொண்டால் மட்டுமே தேர்ந்தெடுக்கப்படுகிறது. வயதுக்கேற்ப குடும்பப் பிரார்த்தனை; ஒரே கிரகத்துக்கான பரிகாரம் மீண்டும் மீண்டும் சேர்க்கப்படாது.
- தேர்ந்தெடுத்த நூல் பலன்கள், பரிகாரங்கள், கோச்சார விளக்கங்களின் அருகில் PDF பக்க இணைப்பு உள்ளது. பழைய heuristic மதிப்பெண்களை நூலின் probability என மாற்றவில்லை.
- புதிய code Swiss கணக்கீடு, network, Firebase, birth chart அல்லது period date ஆகியவற்றை மீண்டும் உருவாக்குவதில்லை. ஏற்கெனவே உள்ள complete-AD அடிப்படையிலான PD கணக்கீடும் அதன் approximate provenance-உம் பாதுகாக்கப்படுகின்றன.

## வைத்திருக்கும் முரண்பாடுகள் மற்றும் வரம்புகள்
