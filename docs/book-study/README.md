# Book source study

Scope: all ten uploaded PDFs, 3,889 PDF pages. The source ledger separates page extraction, available-text review, and visual review.

Nine books' available extracted text has been reviewed in contiguous order. This does not mean every original illustration, table, or legacy-font mantra has been visually verified. Empty pages and unreliable numeric/diagram content remain explicit holds.

The tenth book's native PDF layer omits Tamil text on many pages. The image-based OCR repair workflow reads the actual page raster and bypasses that defective layer. Corrected records must be reviewed before claiming complete source study.

## Source rules

- Cite the exact one-based PDF page; record printed page labels only when actually legible.
- Keep verses, translator commentary, compiled author opinion, and illustrative cases distinct.
- Preserve all AND conditions and explicit exceptions.
- Keep natural and functional planetary roles separate.
- Do not infer missing cusps, strength components, vargas, degrees, nakshatras, or transit facts.
- A sampled transit must occur inside the actual valid dasha/bhukti interval.
- Source schools may use different reference frames, aspects, yogas, node policies, and remedy traditions. Do not silently merge them.
- Book examples and doctrinal percentages are not calibrated forecasting probabilities.
- Recommendations retain optional, feasible devotional or charitable practices. Exact mantras and garbled counts require source verification.

## Reproducible records

The source PDFs remain in books/. The workflows record SHA-256, page sequence, extraction method and unreadable pages. Full page text is retained in short-lived analysis artifacts, not copied into application templates.
