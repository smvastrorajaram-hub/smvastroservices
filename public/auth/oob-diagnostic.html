SMV ASTRO — Firebase Link Diagnostic

This page checks whether a newly generated Firebase email action code is accepted by the smv-astro Authentication project.

Privacy and safety

Paste the complete link only into this page. The link is kept in this browser tab and is sent directly to Firebase for validation. It is not submitted to SMV ASTRO, Render, or Cloudflare servers. Do not send the link or its code to anyone.

This is a read-only validation. It does not verify the email, reset the password, or consume the action code.

After the check, the link text is cleared from the input. The page does not store it in local storage or print it to the browser console.
