Date: 2026-09-27

ROOT CAUSES FIXED
1. Standalone /horoscope page did not define window.SMV_BACKEND_URL. Paid-feature requests therefore went to the frontend host instead of Render.
2. boot.mjs checked ./api/smv-mode relative to /horoscope/, so online engine detection could fall back to offline even while Render was online.
3. Tamil generation path calculated Advanced Analysis without the payment gate. English had the gate; Tamil did not.
4. Paid-feature config failure silently fell back to price=0/free. It now keeps Core Horoscope available but does not unlock paid Advanced/Marriage features.
5. Added public GET /api/smv-mode server contract for online/offline adapter selection.
